About Me

I’m an Army veteran and Computer Science student at Full Sail University, pursuing a career in gameplay programming. My background includes IT support and technical leadership, with experience supporting the Army Reserve component at Fort Bragg as a mobile configuration manager. After transitioning toward software development, I completed Skillspire’s Full-Stack Immersion program before continuing my education at Full Sail.

I’m currently developing Project Eclipse, a C++ combat systems prototype based on my original game concept. Through this project, I’m strengthening my understanding of gameplay logic, data structures, object-oriented programming, and software architecture. My development experience also includes a fitness tracker application, web development, and Microsoft Power Platform work through my internship with NC Tech.

My goal is to become a gameplay developer specializing in combat systems. I’m drawn to fast-paced action, fluid movement, responsive controls, and the way timing and music shape the feel of an encounter. I enjoy breaking down those experiences into systems I can build, test, and refine.

C++ Console Application

Project Eclipse Systems Prototype

A C++ combat systems prototype based on my larger Project Eclipse game concept. The application demonstrates player and enemy interactions, Ether abilities, defensive combat, input validation, and object-oriented programming.

Key Features

  • Combat menu with Basic Attack, Ether Ability, Guard, and return options.
  • Player and enemy health, damage, defense, and defeat logic.
  • Ether resource management and ability costs.
  • Input validation for invalid numeric and non-numeric entries.
  • Refactored combat logic using separate functions and class interactions.

What I Learned

This project strengthened my understanding of object-oriented programming, debugging, references, input validation, Git workflow, and organizing larger sections of C++ logic into cleaner functions.
